# 🤖 VOXA AI

VOXA AI is a modern AI-powered chatbot built using the MERN stack. It provides a clean chat interface with conversation history, Markdown support, syntax highlighting for code responses, and persistent chat threads.

## 🚀 Features

* 💬 AI-powered conversations
* 📝 Persistent chat history
* ➕ Create new conversations
* 🔄 Continue previous chats
* 🎨 Clean and responsive UI
* 📄 Markdown rendering
* 💻 Code syntax highlighting
* ⚡ Fast and lightweight interface

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/VOXA.git
cd VOXA
```

### 2. Install Backend Dependencies

```bash
cd backend
npm install
```

### 3. Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

---

## 🔐 Environment Variables

Create a `.env` file inside the **backend** directory.

```env
PORT=8080
MONGODB_URI=YOUR_MONGODB_CONNECTION_STRING
OPENROUTER_API_KEY=YOUR_OPENROUTER_API_KEY
```

Create a `.env` file inside the **frontend** directory.

```env
VITE_BACKEND_URL=http://localhost:8080
```

---

## ▶️ Running the Project

### Start Backend

```bash
cd backend
npm start
```

### Start Frontend

```bash
cd frontend
npm run dev
```
